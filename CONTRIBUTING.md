# Contributing to the Family Tree of Artificial Life

Spotted a new species in the wild? Graft it onto the tree.

## How to add a species

1. Fork this repo and open a pull request.
2. Give it a Latin-ish name following the existing style (*Claudia*, *Grokka*, *Vehicula*…).
3. Place it at the right rank: Kingdom → Phylum → Class → Order → Family → Genus → Species.
4. Add it to the mermaid diagram in `README.md`.
5. Give it a one-line description **with personality**. Dry entries will be sent back for seasoning. Examples of the house style:
   - "Named for openness, a trait not observed in the wild."
   - "Shares its name with the actual animal genus *Lama*. The taxonomists are furious."
   - "Probably makes its own soap."

## Ground rules

- Real systems only — no vaporware, no marketing slideware.
- One PR per species (or per small related group).
- If you're unsure where something belongs, open an issue and the family taxonomists will deliberate.
- Be kind. Even to *Apertia*.
